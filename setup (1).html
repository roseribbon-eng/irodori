ONLINE EXHIBITION

かんたん設定

入力して、いちばん下のボタンを押すだけです。

はじめに確認してください。
このすぐ下に、白いのような入力欄は見えていますか。
文字だけが並んでいて入力欄が見えないときは、 アプリの中で開いています。
いったんファイルを端末に保存してから、 Chrome などのブラウザで開き直してください。
すでに作ったことがある方へ。
いまお使いの index.html を読み込むと、入力欄に前の内容が入ります。 直したいところだけ書き換えてください。

① あなたのこと

入口とプロフィールに出ます。あとから何度でも作り直せます。

② リンク

URLを入れた分だけ、ボタンが出ます。空のままなら出ません。
ボタンの文字は自由に変えられます（X、YouTube、note、LINE など）。
見てほしいものを2〜3つに絞ると、押してもらいやすくなります。

③ 部屋と作品

作品のタイトルは、拡大したときに出ます。
ファイル名は決まっているので、その名前で画像を用意してください。

このあとの流れ
1. 下の「ファイルを作る」を押すと index.html ができます
2. 画像を art01.png 〜 art08.png の名前にします
3. GitHub に index.html と画像をまとめてアップロードします
